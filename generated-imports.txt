# The packages outside the standard library that the Go code this SDK
# generates for a new module imports: its dispatcher, its module client and
# its bindings, with the defaults of a new module. Engines read this list to
# pre-warm the builds of these packages, with dagger.io/dagger at
# defaultTarget (versions.toml).
#
# The e2e check generatedImportsCheck fails when a newly generated module's
# code imports anything else, or no longer imports one of these.
